Methodology

This page combines GDP data for global countries/economies and U.S. states into one comparison table. The values are intended for scale comparison and web presentation.

Country/economy figures and U.S. state figures may come from different official release streams and schedules, so this should be treated as a combined comparison dataset rather than a perfectly uniform official ranking.

To update the page later, replace the JSON file with a newer version while keeping the same field names.
